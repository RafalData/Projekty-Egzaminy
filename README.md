## OPISY PROJEKTÓW I ICH CELÓW

### [The Berka Dataset](./The%20Berka%20Dataset)
Baza danych mająca na celu pokazać umiejętność posługiwania się SQL na dużych zbiorach danych. W tym przypadku wykorzystałem dane czeskiego banku, które zostały przetłumaczone.

### [Wydatki](./Wydatki)
Baza danych, która powstała aby pokazać umiejętność posługiwania się SQL przy tworzeniu baz danych za pomocą kodu.
